# 初期実装の開発記録

## 実装範囲

Djangoの環境設定、PostgreSQL接続、カスタム利用者、部署・対応チーム・カテゴリ、ログイン・パスワード変更、社員向け新規登録・本人の一覧・詳細を実装しました。

新規登録はログイン利用者を依頼者に固定します。画面入力で依頼者・担当者・状態を指定しても採用しません。受付時の部署を文字列として記録し、異動後も保持します。登録と受付イベントは同じトランザクションで保存し、利用者に結び付けた署名付き送信キーで二重登録を防ぎます。

この段階では、担当者画面、代理登録、担当割当、追加情報、公開回答、内部メモ、状態更新、FAQ、通知、分析は未実装です。状態の定義とDB制約は今後の更新処理に備えて用意しています。

## 検証記録（2026-10-13）

- Djangoのシステムチェック：成功。
- マイグレーションの差分チェック：変更なし。
- Ruffの静的検査・書式チェック：成功。
- wheelとソース配布物のビルド：成功。
- 社員向けHTTP操作などの17件のテスト：暫定SQLite設定で成功。

開発エージェントの環境ではPostgreSQLを非root利用者として起動できなかったため、ローカルでPostgreSQLの動作は検証できていません。一時的なSQLite設定はリポジトリへ含めていません。PostgreSQLでの最終検証用としてGitHub Actionsに同じテストとマイグレーション検査を設定しました。CIの成功確認前にPostgreSQL検証済みとは扱わないでください。

ブラウザの目視確認は未実施です。HTTPテストで画面応答・エスケープ・本人以外の拒否を検証しています。
